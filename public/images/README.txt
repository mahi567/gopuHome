The photos in this folder are free stock photos from Unsplash (unsplash.com,
Unsplash licence). They are stand-ins and do NOT show the real properties.

To use your own photos, replace each file keeping the same file name:

  hero.jpg       (large banner photo on the home page)
  flat-1.jpg     flat-2.jpg
  hostel-1.jpg   hostel-2.jpg   hostel-3.jpg   hostel-4.jpg
  studio-1.jpg   studio-2.jpg
  lodge-1.jpg    lodge-2.jpg

Landscape photos (about 1200 x 900) look best.
To use different file names, change the "image" line of that stay in js/data.js.
